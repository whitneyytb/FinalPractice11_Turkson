Practice 11: Deploying My Application

Platform Used:
Render

Description:
For this practice, I deployed my Node.js and Express application using Render. I used the Express server from my previous practices and prepared it for deployment by making sure my package.json file included a start script.

Key Steps:
1. Created a GitHub repository for my project.
2. Uploaded my project files to GitHub, including server.js and package.json.
3. Connected my GitHub repository to Render.
4. Created a new Web Service on Render.
5. Set the build command to npm install.
6. Set the start command to npm start.
7. Deployed the web service.
8. Tested the live URL in my browser to make sure the application worked.

Issues Encountered:
I had some issues connecting my local project folder to GitHub and pushing the files at first. I fixed this by using GitHub Desktop, creating the repository correctly, and publishing the project files to GitHub. I also made sure my package.json had the correct start command so Render could run the server.

Live Application URL:
https://finalpractice11-turkson.onrender.com

API Endpoint Tested:

This deployment helped me understand how a local Node.js and Express application can be published online and accessed through a live URL.
